# LOCO GAME

Online X O game. The application lives in the `el-loco/` folder
(see `el-loco/README.md` for running, HTTPS, TURN and Render setup).

Render settings: Root Directory = `el-loco`, Build = `pip install -r requirements.txt`,
Start = `gunicorn --threads 100 -w 1 app:app`.
